# П10 «Звонки и SMS» — план работ

> **Для исполнителя:** задачи по порядку, флажки `- [ ]`. Исполнение — в этой сессии (superpowers:executing-plans),
> в конце — проверка всей ветки.

**Goal:** звонки и SMS с телефона владельца попадают в ленту Stream; после разговора — описание из уведомления.

**Architecture:** сервер получает два новых вида события (`call`, `sms`) и адреса `/api/phone/*` с отдельным
токеном; id звонка и SMS выводится из их данных одинаково на сервере и на телефоне. PWA рисует пузыри звонка и
SMS. Отдельное приложение на Kotlin читает журнал вызовов и SMS, шлёт новое через WorkManager и показывает
уведомление с ответом.

**Tech Stack:** Node 24 + TypeScript без сборки, `node:sqlite`, `node --test`; PWA на обычном JS; Android:
Kotlin, Gradle 9.1 (кеш уже есть), AndroidX Core, WorkManager, JUnit 4.

**Spec:** `docs/plans/2026-11-17-p10-calls.md` (читать вместе с этим планом).

## Global Constraints

- Event v1 остаётся v1: `kind` += `call`, `sms`; `source: android_phone`; `author: me`.
- `direction` звонка ∈ `in`, `out`, `missed`, `rejected`, `unknown`; SMS ∈ `in`, `out`.
- `STREAM_PHONE_TOKEN` ≥ 32 символов (`captureConfig.min_owner_token_length`); открывает только `/api/phone/*`.
- Ключ id: `call|<number>|<started_ms>`, `sms|<direction>|<number>|<sent_ms>|<text>` — время в миллисекундах
  эпохи целым числом, номер как пришёл после `trim()` (пустой — пустая строка).
- id из ключа: sha256(UTF-8 ключа), первые 16 байт, `b[6] = (b[6] & 0x0f) | 0x50`, `b[8] = (b[8] & 0x3f) | 0x80`,
  запись строчными hex `8-4-4-4-12`. Один и тот же алгоритм в `src/server/phone.ts` и `PhoneIds.kt`.
- Описание: `{ note_id, text, written_at }`, `written_at` — миллисекунды с телефона (повтор того же
  `note_id` даёт тот же `ts` и тот же хеш тела → 200, а не 409).
- Android: `minSdk 29`, `targetSdk 36`, пакет `pl.sekond.stream.phone`, `allowBackup=false`, без Compose и OkHttp.
- Тексты интерфейса — по-русски; код, имена, коммиты — по-английски. Номера и тексты SMS в тестах — вымышленные.
- Ключ подписи и пароль — вне git (`%USERPROFILE%\.stream\stream-phone.jks`, `android/keystore.local.properties`).

## Review Focus

1. **Повторная отправка с другим временем** — телефон дважды шлёт тот же звонок (сеть оборвалась после
   записи) → второй ответ 200 с тем же id, не 409. Тест в задаче 2.
2. **Номер скрыт** (пустой `number`, тип `MISSED`) → звонок пишется, в ленте «Скрытый номер». Тесты в задачах 2 и 3.
3. **Описание раньше звонка** — ответ из уведомления без сети, звонок ещё в очереди → описание уходит после
   звонка, не получает 404 навсегда. Тест-порядок в задаче 5 (сверка шлёт заметки после звонков); 404 от
   сервера оставляет заметку в очереди с повтором.
4. **SMS с банка и коды** — отправитель `mBank`, `DHL`, короткий `7911` → не уходит, `_ID` запоминается. Тест в задаче 4.
5. **Токен телефона на чужом адресе** — `/api/events`, `/api/live`, `/api/media/*` с ним → 401. Тест в задаче 2.
