# П1 — Строка меток над вводом

Решения: `decisions.md` 2026-11-11 «Метка и поле — одно понятие». Концепция: `CONCEPT.md` §2.2.

## Готово, когда

- [x] Над строкой ввода — строка меток с горизонтальной прокруткой: предложенные неактивны, включённые
  подсвечены, автоматические отмечены отдельно.
- [x] Подсказки меняются по ходу набора; при пустом поле — самые частые метки.
- [x] При высокой уверенности метка включается сама; снятая владельцем автоматическая метка в этом черновике
  больше не включается.
- [x] `#слово` в тексте включает метку `#слово`.
- [x] В событии сохраняется `payload.data.tagging`: предложено, включилось само, включил владелец, снял
  владелец, версия подсказчика. Сервер проверяет согласованность с `payload.tags`.
- [x] Работает без сети: подбор на телефоне, по журналу в кеше и словарю.

## Данные

- `registry/tags.json` — словарь: `tag`, `intent` (если метка с переменными), `hints` (начала слов-признаков);
  `engine`, `auto_threshold`, `suggest_limit`. Заменяет `quick_tags` в `registry/capture.json`.
- Event v1, необязательное `payload.data.tagging = { engine, suggested[], auto[], owner_on[], owner_off[] }`.
  Правила: `auto` и `owner_on` входят в `payload.tags`; `owner_off` не входит; пересечений нет.

## Подбор (`web/suggest.js`, чистая функция)

- Частота `f` — сколько раз метка была в сообщениях (недавние весят больше), нормировано `n / (n + 3)`.
- Совпадение `m` — сколько слов-признаков метки начинают слова текста: `1 − 0,5^k`.
- Уверенность `c = 1 − (1 − m)(1 − 0,5·f)`, умноженная на долю «не сняли» по прошлым автоматическим
  включениям этой метки.
- Автовключение — при `c ≥ auto_threshold` и непустом тексте.

## Не входит

Переменные меток и их заполнение (П5), метки-ссылки на темы (П3), подсказки от ИИ (шаг 3), обратная связь при
правке сообщения (П5).
