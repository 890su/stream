# Менеджер задач с ИИ — сверка ТЗ с Stream и этапы

> ТЗ: `docs/plans/2026-11-19-task-manager-spec.md` (утверждено 2026-11-19). Здесь — что из него уже есть, чего нет,
> и порядок этапов. Каждый этап — своя польза и свой план; следующий — после недели использования (правило 12).

## Сверка

| ТЗ | Есть в Stream | Нет / не так |
|---|---|---|
| Дело: роли, статусы, срок, отложить, чеклист, источники, проект | ✅ `task_change`, `taskfold.js`, `projects.js` | — |
| Положения «моё / поручено / жду / команда» (4.2) | ✅ фильтры «Все мои», «Контроль», «Жду», «Команда» | одним взглядом не видно — разнесено по чипам |
| Важность вычисляется (4.5) | ❌ порядок — по сроку или по дате изменения | формула |
| Длительность, «где остановился» (4.1) | ❌ | поля и учёт времени «в работе» |
| Пульт (5): В работе · Срочное · Горит · До события · Слежу · ИИ подготовил · Проекты · Дальше | ⚠️ «Сегодня» разделами (Просрочено · Сегодня · Следующее · Проверить · Разобрать · Дальше) | блоки, однозначность, свёртка пустых |
| Одно дело в работе, пауза и возврат (5.4) | ⚠️ статус `doing` есть, никто его не ставит | «▶ В работу», стопка, «Вернуться к…» |
| Срочное входящее, «Напарнику», «Раздать» (5.5) | ⚠️ беседы «срочно / ждёт меня»; «Поручить…» без отправки | блок, поручение через бота, раздача |
| ИИ подготовил: черновики к «Да» (5.3, 6.3) | ❌ (ответ пишет владелец; разбор ставит задачи) | черновики как события, очередь одобрения, лестница доверия |
| Следующий шаг одной фразой (4.1) | ⚠️ «следующее действие» есть только у проекта с целью | поле у каждого дела от разбора |
| Слежение по таймерам (6.2) | ❌ «Жду» без таймера | правила-таймеры без ИИ, черновики напоминаний |
| Ошибки ИИ (6.5) | ✅ «О каком деле?», «В дело…», «Отдельной задачей», правки | «Не задача» одним касанием |
| Динамика проектов (7) | ⚠️ дерево со счётчиками, «Нет следующего шага» | сделано / пришло / стоит за 7 дней, здоровье |
| Сводки (8) | ❌ | утро / вечер / неделя |
| Голосовые команды (9) | ❌ (голос → текст — шаг 2) | команда или запись — решает ИИ |
| Напарники через бота (10) | ❌ (П14 этап 3) | бот задач |
| Отчёт из переписки, учёт (11) | ⚠️ «Не учтено», «Заполнить отчёт» руками | заполнение ИИ, отправка в учёт |
| Push по трём случаям (12) | ❌ (PWA без Web Push) | Web Push, затем натив |
| Google Calendar: занятое, окно, дела на выезде (5.1) | ❌ | коннектор календаря |

## Этапы

| # | Этап | Польза на следующий день | Зависит от | Без ИИ? |
|---|---|---|---|---|
| **1** | **Пульт и фокус**: пульт по умолчанию в «Задачах» (В работе · Горит · Сегодня · Слежу · Проекты · Дальше), формула важности, «▶ В работу», стопка паузы, «Вернуться к…», время в работе, динамика и здоровье проектов | вся ситуация на одном экране; прерывание не теряет дело | — | да |
| 2 | **Слежение и «ИИ подготовил»**: таймеры «жду / поручено» (правила), черновики напоминаний и ответов, очередь одобрения с «Да / Поправить / Не надо», пачкой; следующий шаг и значок 🤖 ✋ 👤 от разбора (`triage-ai-v9`) | никто не молчит незаметно; ответы — одним «Да» | 1 | таймеры — да, черновики — ИИ |
| 3 | **Срочное и напарники**: блок «⚡ Срочное», «Сейчас / Ответ / Напарнику / Позже», бот задач для напарников (П14 этап 3: «Принял / Не могу / Сделал»), «Раздать» с нагрузкой | срочное раздаётся, не копится | 2 | — |
| 4 | **Календарь и время**: Google Calendar (занятое время), окно «До события», прогноз длительности по факту, мелочи пачкой, дела к выезду | план — то, что влезает | 1 (время в работе копит историю) | да |
| 5 | **Сводки и push**: утро / вечер / неделя (приложение и Telegram), push по трём случаям с кнопками | ничего не копится молча (закрывает «сток без выхода» из разбора 2026-11-19) | 2 | да |
| 6 | **Голосовые команды**: строка ввода понимает «перенеси…», «поручи…», «что горит?» | работа одной фразой | шаг 2 MVP (голос → текст) | ИИ |
| 7 | **Отчёт и учёт**: ИИ заполняет отчёт из переписки, «Отправить в учёт», статус оплаты, деньги проекта | работа доходит до счёта | ❓ решение владельца, куда отдавать (ТЗ §15 п. 4) | ИИ |

Порядок: 1 → 2 → (3 и 4 в любом порядке) → 5 → 6, 7. Этап 1 нужен всем: он даёт экран, куда кладут результат
остальные. Этап 4 можно взять раньше 3, если календарь важнее напарников.

## Что меняется в концепции (при этапе 1)

- `CONCEPT.md` §5: «Задачи» открываются пультом; «Сегодня» остаётся списком-чипом. §2.8: одно дело «в работе»,
  пауза с `resume_note`, время в работе из истории.
- `decisions.md`: пульт вместо «Сегодня» по умолчанию; лимит — время, не число дел; `resume_note` в контракте задачи.
