# Работа с задачей: касание, долгое нажатие, смахивание, карточка — проект

> Статус: **утверждено, сделано** (2026-11-19). Вариант Б выбран владельцем («норм»); смахивание со значком — его
> добавление. Основа — ТЗ менеджера задач (`docs/plans/2026-11-19-task-manager-spec.md` §2 мерки, §5.2 строка).

## Зачем

Карточка — длинная лента: до переписки и телефона клиента надо листать, действия — текстовыми кнопками, нет «▶ В
работу», «Ответить», следующего шага. Строка не умеет действовать без карточки, кроме «Готово» и «Когда?»; при
смахивании не видно, что произойдёт.

## Решения

**1. Жесты строки задачи** (пульт, списки, плашки в беседе):

| Жест | Что |
|---|---|
| Касание по строке | карточка справа |
| Касание по кружку | «Готово» (как сейчас) |
| Долгое нажатие | снизу выезжает **панель действий** — те же значки, что внизу карточки; карточка не открывается |
| Смахивание вправо | «Готово» |
| Смахивание влево | «Когда?» |

**2. Значок при смахивании.** На месте, которое освобождает строка, — значок и подпись действия: вправо — «✓ Готово»
(зелёный), влево — «🕒 Когда?» (синий). До порога значок бледный, после порога — яркий и чуть крупнее: видно, что
отпускание сработает. Так же у строки беседы: влево — «🗄 В архив», вправо — «☑ Задача».

**3. Панель действий** — одна раскладка везде (внизу карточки, по долгому нажатию, позже — в уведомлениях):

```
 ✓        ▶          🕒       👤         💬        ⋯
Готово  В работу   Когда   Поручить  Ответить   Ещё
```
- «Готово» — у задачи «на проверке» это «Проверил»; закрытая — «Вернуть».
- «▶ В работу» — моя задача не в работе; в работе — «⏸ Пауза».
- «🕒 Когда» — сегодня / завтра / на неделе / дата.
- «👤 Поручить» — люди из переписки задачи, «ИИ», «Другой…».
- «💬 Ответить» — открывает беседу задачи с полем ввода (если у задачи есть чат); иначе значка нет.
- «⋯ Ещё» — Принять, Жду…, Отложить…, Отменить.
Выбор второго уровня (люди, даты) появляется над панелью, в ней же; системная «назад» закрывает его, затем панель.

**4. Карточка задачи** — короткая сверху, подробности свёрнуты:

```
┌──────────────────────────────┐
│ Глеб Пример: роутер        ✎ │  название (касание — переименовать)
│ ◆ ул. Пробная 5 · сегодня · в работе │  контрагент · срок · статус
│ дальше: проверить Wi-Fi      │  где остановился / первый пункт
│ [Задача выполнена?  Да  Нет] │  если разбор увидел «готово»
│ ☑ Чеклист 1/3              ▾ │  открыт, если есть пункты
│ 💬 Переписка · 7           ▾ │  последние 3, «показать все»
│ 📞 +48 600… · 📍 Пробная 5   │  звонок и карта одним касанием
│ ▸ Подробности                │  проект, контрагент, роли, заметка
│ ▸ Отчёт / История            │  свёрнуты
├──────────────────────────────┤
│ ✓   ▶   🕒   👤   💬   ⋯     │  панель действий, всегда видна
└──────────────────────────────┘
```
- Телефон и адрес — из справочника (человек-автор задачи, контрагент); телефон — ссылка `tel:`, адрес — ссылка на карты.
- Срок больше не отдельным блоком чипов — в шапке и в «🕒 Когда».
- Свёрнутость разделов запоминается на устройстве.

## Подходы (рассмотрено)

| | Подход | Почему нет / да |
|---|---|---|
| А | Касание — панель, долгое — карточка | карточку не найти; долгое нажатие в ленте уже — выделение |
| **Б (выбран)** | **Касание — карточка с панелью внизу; долгое — та же панель без карточки** | смотреть — одно касание, действовать без карточки — долгое; одна раскладка |
| В | Строка разворачивается в списке | строки прыгают, на телефоне занимает пол-экрана |

## Как сделать (план)

1. `web/swipe.js` — подложка со значком: чистая `revealOf(dx, labels) → { side, label, armed }`; строки задач,
   плашки, строки бесед передают свои значки. Тест на пороги и стороны.
2. `web/taskbar.js` — чистая `barActions(task, { mine, hasChat }) → [{ id, icon, label }]` (тест по статусам и
   ролям) и панель (DOM) с вторым уровнем; `web/tasksheet.js` — выезжающая снизу панель для долгого нажатия
   (закрытие — касание мимо, «назад» через `backclose.js`). Долгое нажатие — в `taskquick.js` (450 мс без сдвига; не
   мешает прокрутке и смахиванию).
3. `web/taskdetails.js` — шапка, «дальше», разделы `<details>` с запоминанием, контакт из справочника, панель внизу
   вместо текстовых кнопок и блока срока; файл делится, если перерастёт ~300 строк.
4. Проверка в браузере на 375 px (жесты — нажатиями мышью с эмуляцией касания там, где возможно), тесты, выкладка.

## Остаётся исполнителю

Значки (символы или SVG в стиле текущих), цвета из токенов темы, точные отступы, анимация выезда (по «уменьшить
движение» — без анимации).
