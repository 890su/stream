# Google Календарь в Stream

Stream читает календари владельца (оба аккаунта Google) и показывает их события в правой панели «План» серыми
строками среди задач — так видна реальная загрузка дня. Это этап 1; этап 2 — календарь «Stream», синхронизированный с
задачами в обе стороны (`docs/plans/2026-11-20-google-calendar-design.md`).

Вход — через **свой** проект Google Cloud: ключи доступа выдаются только Stream и хранятся на сервере, в томе данных
`/srv/stream/data/google/` (не в git, не в журнале). Права — только календарь (и адрес аккаунта, чтобы их различать).

## Настроить (один раз, ~10 минут)

1. Открыть <https://console.cloud.google.com/>, войти любым из своих аккаунтов Google.
2. Сверху — выбор проекта → «Новый проект» → имя «Stream» → «Создать». Выбрать его.
3. «APIs & Services» → «Library» → найти **Google Calendar API** → «Enable».
4. «APIs & Services» → «OAuth consent screen» (или «Google Auth Platform» → «Branding»):
   - тип — **External**, имя приложения «Stream», почта поддержки — своя;
   - «Audience» → «Publish app» → статус **In production** («В работе»). Без этого вход перестаёт работать через
     7 дней. Проверка Google не нужна — приложение личное.
5. «APIs & Services» → «Credentials» (или «Clients») → «Create credentials» → **OAuth client ID**:
   - тип — **Web application**, имя «Stream»;
   - «Authorized redirect URIs» → добавить ровно `https://stream.sekond.pl/api/google/callback`;
   - «Create» — появятся **Client ID** и **Client secret**.
6. На сервере дописать в `/srv/stream/.env` две строки (значения из шага 5):
   ```
   STREAM_GOOGLE_CLIENT_ID=…
   STREAM_GOOGLE_CLIENT_SECRET=…
   ```
   и выложить заново (агент: `install.sh main`) — `install.sh` напишет `Google: client set`.
7. В Stream: ⋮ → «Система» → «Google Календарь» → **«Подключить Google»** → выбрать аккаунт. Google предупредит
   «Приложение не проверено» — это нормально для личного приложения: «Дополнительно» → «Перейти на страницу Stream» →
   разрешить доступ к календарю. Вернувшись, Stream скажет «Google подключён». Повторить «Подключить ещё аккаунт
   Google» для второго аккаунта.

Через минуту события появятся в «Плане» (📅). На «Системе» под «Показывать в «Плане»» — переключатель на каждый
календарь; праздники выключены сразу.

## Если что-то не так

| На «Системе» | Что значит | Что делать |
|---|---|---|
| «Не настроен» | нет строк из шага 6 в `.env` | шаги 1–6 |
| «Google Календарь — нужен вход», аккаунтов нет | клиент есть, вход не сделан | «Подключить Google» |
| у аккаунта «нужен вход» | доступ отозван или истёк (приложение не «In production») | шаг 4, затем «Подключить» этот аккаунт снова |
| «ошибка» | Google не ответил | ничего: Stream повторит сам, в «Плане» — последние полученные события |
| после входа «Не удалось подключить Google» | неверный адрес возврата или секрет | сверить шаг 5 и строки в `.env` |

## Отключить

«Система» → у аккаунта «Отключить» (ключ стирается на сервере). Совсем отозвать доступ — в аккаунте Google:
<https://myaccount.google.com/permissions> → «Stream» → «Удалить доступ».
