# «Stream · телефон» — установка на телефон

Отдельное приложение пишет в ленту Stream звонки и SMS и после разговора спрашивает «О чём был звонок?»
(`CONCEPT.md` §8.1, `archive/plans/2026-11-17-p10-calls.md`). Код — `android/`.

## Сборка (на компьютере)

```powershell
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
cd android
.\gradlew.bat testDebugUnitTest assembleRelease
```

APK: `android/app/build/outputs/apk/release/app-release.apk`. Подпись — ключ `%USERPROFILE%\.stream\stream-phone.jks`,
пароль — `android/keystore.local.properties` (оба вне git). **Ключ сохранить в надёжном месте:** без него новая
версия не встанет поверх установленной — придётся удалять приложение и настраивать заново.

Каждая новая версия — `versionCode` +1 в `android/app/build.gradle.kts`.

## Установка

Через USB: на телефоне включить «Параметры разработчика» → «Отладка по USB», подключить кабель и разрешить
компьютер. Затем:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" install -r stream-phone-0.1.0.apk
```

Без кабеля: передать APK себе на телефон (Telegram «Избранное», Drive) и открыть; Android спросит разрешение
устанавливать приложения из этого источника. Приложение не из Google Play: Play Protect может предупредить —
«Всё равно установить».

## Настройка (один раз)

1. Токен телефона на сервере: `sudo grep PHONE /srv/stream/.env` (создаётся `install.sh`).
2. В приложении: адрес `https://stream.sekond.pl`, токен телефона → «Сохранить и проверить связь» → «✓ Связь есть».
3. «Выдать разрешения»: звонки, телефон, SMS, уведомления. Если Android пишет, что настройка ограничена:
   «О приложении» → ⋮ → «Разрешить ограниченные настройки», затем снова «Выдать разрешения».
4. «Не экономить батарею» — иначе Android усыпляет приложение и звонки приходят только при сверке раз в 15 минут.
5. На некоторых телефонах (Xiaomi, Huawei, Samsung) ещё — автозапуск разрешить, приложение не «оптимизировать».

Старые звонки и SMS не выгружаются: в ленту попадает только то, что случилось после первой сверки.

## Проверка

- Позвонить себе с другого телефона, поговорить несколько секунд → в ленте «📞 Входящий · … с», уведомление
  «О чём был звонок?» → ответить → ответ под звонком.
- Пропущенный звонок → в ленте «Пропущенный», уведомления нет.
- SMS с другого телефона → в ленте за несколько секунд; отправленное SMS — до 15 минут.
- SMS от банка или службы доставки (имя вместо номера) в ленту не попадает.
- Режим полёта → звонок → сеть → звонок доходит, без дублей.

## Проверено на эмуляторе (2026-11-17, образ API 37)

Отвеченный звонок с уведомлением и ответом из шторки; пропущенный без уведомления; SMS с номера — в ленте,
от `mBank` — нет; звонки без сети дошли после её появления. На настоящем телефоне — открыто (владелец).
