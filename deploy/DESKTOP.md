# Рабочий стол агентов на srv-150

Лёгкий виртуальный компьютер для сеансов агентов: Ubuntu 22.04, Openbox и панель tint2, экран 1280×800, вход
через браузер (noVNC). Первое приложение — Viber для Linux на номере владельца; другие программы ставятся сюда же.
Решение — `decisions.md`, 2026-11-20.

## Что внутри

| Что | Где |
|---|---|
| Образ и запуск | `deploy/desktop/` — `Dockerfile`, `compose.yml`, `supervisord.conf` |
| Контейнер | `agent-desktop`, проект compose `desktop`, пользователь `agent` (uid 1000), дисплей `:1` |
| Профили программ (вход Viber, история) | том `desktop_home` → `/home/agent`; переживает пересборку |
| Уведомления рабочего стола | `notify-log` пишет каждое в `/home/agent/inbox/notifications.jsonl` (на экране не показываются) |
| Отправка в Viber | `viber-send "<имя>" "<текст>"`; места на экране — `bin/viber-ui.env`; снимок каждой отправки — `/home/agent/sent/` |
| Снимок экрана | `desktop-shot [файл.png]` |

Ресурсы: на сервере 1 ядро и 1,9 ГБ; контейнеру — до 1,2 ГБ памяти и 0,9 ядра. Тяжёлый браузер рядом с Viber — на
пределе.

## Открыть экран

noVNC слушает только `127.0.0.1:6080` на сервере. С компьютера владельца:

```powershell
ssh -i ~/.ssh/id_ed25519 -N -L 6080:127.0.0.1:6080 admin890brain@192.168.0.149
```

и в браузере http://localhost:6080 → «Подключиться». Пароля нет: доступ — только через SSH-ключ.

## Первый вход в Viber

Viber на столе — дополнительное устройство номера. Открыть экран (выше) на компьютере, на телефоне Viber →
«Ещё» → QR-сканер → навести на QR-код на экране. Если на телефоне Viber отключить или удалить, отключится и стол.

## Выкладка и обновление

```powershell
ssh -i ~/.ssh/id_ed25519 admin890brain@192.168.0.149 "cd /srv/stream/app/deploy/desktop && docker compose up -d --build"
```

Код берётся из того же клона, что и Stream (`install.sh` обновляет его). Команды агентов:
`docker exec -u agent agent-desktop viber-send "Имя" "Текст"`, `docker exec -u agent agent-desktop desktop-shot > s.png`.

## Чтение входящих

База сообщений Viber для компьютера (`~/.ViberPC/<номер>/viber.db`) зашифрована, обычным SQLite не читается. Поэтому
входящие берутся из уведомлений: `notify-log` занимает службу уведомлений рабочего стола и пишет каждое
уведомление строкой JSON (программа, заголовок = отправитель или чат, текст). ❓ Формат уведомлений Viber и то,
приходят ли они при открытом окне, проверяются на первых настоящих входящих.

## Отправка: как и почему так

Скрипт делает то же, что человек: поиск → имя → первый результат → проверка заголовка чата распознаванием текста →
вставка текста → Enter, с паузами как у человека и по одной отправке за раз. Если открылся чужой чат, ничего не
набирается (код 3) и остаётся снимок `…-mismatch.png`. Имя — как в списке контактов Viber (не короче двух букв);
`VIBER_SEND_DRY=1` открывает и проверяет чат, ничего не набирая. Проверено 2026-11-20 на «Моих заметках»: отправка
и отказ на чужом чате. Viber не видит, нажимает ли клавиши человек или скрипт; риск
блокировки — от поведения (массовые сообщения, много новых людей подряд), поэтому только ответы и только по одному.
