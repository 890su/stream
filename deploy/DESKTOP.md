# Рабочий стол агентов на srv-150

Лёгкий виртуальный компьютер для сеансов агентов: Ubuntu 22.04, Openbox и панель tint2, экран 1280×800, вход
через браузер (noVNC). Первое приложение — Viber для Linux на номере владельца; другие программы ставятся сюда же.
Решение — `decisions.md`, 2026-11-20.

## Что внутри

| Что | Где |
|---|---|
| Образ и запуск | `deploy/desktop/` — `Dockerfile`, `compose.yml`, `supervisord.conf` |
| Контейнер | `agent-desktop`, проект compose `desktop`, пользователь `agent` (uid 1000), дисплей `:1` |
| Профили программ (вход Viber, история) | том `desktop_home` → `/home/agent`; переживает пересборку |
| Уведомления рабочего стола | `notify-log` пишет каждое в `/home/agent/inbox/notifications.jsonl` (на экране не показываются) |
| Отправка в Viber | `viber-send "<номер или имя>" "<текст>"`; места на экране — `bin/viber-ui.env`; снимок каждой отправки — `/home/agent/sent/` |
| Кто это (имя и номер) | `viber-whois "<номер или имя>"` → `{"name","phone"}`; общие шаги — `bin/viber-lib.sh` |
| Самопроверка кликов | `viber-selftest` → `/home/agent/inbox/selftest.json`, снимки шагов — `/home/agent/selftest/<время>/` |
| Состояние канала | `viber-health` каждые 5 мин → `/home/agent/inbox/health.json` |
| Мост в Stream | `viber-bridge` (supervisor `bridge`, журнал `/home/agent/bridge.log`, состояние `/home/agent/inbox/bridge-state.json`) |
| Снимок экрана | `desktop-shot [файл.png]` |

Ресурсы: на сервере 1 ядро и 1,9 ГБ; контейнеру — до 1,2 ГБ памяти и 0,9 ядра. Тяжёлый браузер рядом с Viber — на
пределе.

## Открыть экран

noVNC слушает только `127.0.0.1:6080` на сервере. С компьютера владельца:

```powershell
ssh -i ~/.ssh/id_ed25519 -N -L 6080:127.0.0.1:6080 admin890brain@192.168.0.149
```

и в браузере http://localhost:6080 → «Подключиться». Пароля нет: доступ — только через SSH-ключ.

## Первый вход в Viber

Viber на столе — дополнительное устройство номера. Открыть экран (выше) на компьютере, на телефоне Viber →
«Ещё» → QR-сканер → навести на QR-код на экране. Если на телефоне Viber отключить или удалить, отключится и стол.

## Выкладка и обновление

```powershell
ssh -i ~/.ssh/id_ed25519 admin890brain@192.168.0.149 "cd /srv/stream/app/deploy/desktop && docker compose up -d --build"
```

Код берётся из того же клона, что и Stream (`install.sh` обновляет его). Machine-id хранится в томе
(`/home/agent/.machine-id`, `desktop-start`), MAC закреплён: пересборка образа не сбрасывает вход Viber (сбросила
2026-11-20, когда id создавался заново). **После каждой пересборки или обновления Viber агент запускает
`viber-selftest` и просматривает снимки шагов** (попали ли клики куда надо), затем ставит отметку в `PLAN.md`.
Команды агентов:
`docker exec -u agent agent-desktop viber-send "Имя" "Текст"`, `docker exec -u agent agent-desktop desktop-shot > s.png`.

## Чтение входящих

База сообщений Viber для компьютера (`~/.ViberPC/<номер>/viber.db`) зашифрована, обычным SQLite не читается. Поэтому
входящие берутся из уведомлений: `notify-log` занимает службу уведомлений рабочего стола и пишет каждое
уведомление строкой JSON. Viber шлёт их и при открытом окне (проверено 2026-11-20): `app` = `ViberPC`,
`summary` = имя отправителя в невидимых ограничителях U+2068…U+2069, `body` = текст, `hints.category` =
`im.received`. Служебные тоже приходят так («Viber обновлён», версия в тексте). ❓ Как выглядит сообщение в группе.

## Номер отправителя

В уведомлении — только имя. Номер даёт меню правого клика по заголовку чата: «Копировать имя», «Скопировать
номер» — точно, через буфер обмена (`viber-whois`). Распознавание шапки — запасной путь (у групп меню нет).
У человека не из контактов Viber на компьютере номер скрывает («Неизвестно … не является вашим контактом»,
номер пустой): такая переписка становится беседой без номера; владелец добавит контакт в Viber, или кто это —
выяснится из переписки (решение владельца 2026-11-20). У групп и «Моих заметок» номера нет (`phone: null`).
Открытый чат на телефоне считается прочитанным. Проверено 2026-11-20: контакт по номеру и по имени — имя и номер
точные; заметки, группа — без номера; чужой номер и имя — отказ.

Шрифт эмодзи (`fonts-noto-color-emoji`) в образ не ставится: Viber брал из него цифры и пробелы, номера выходили
мелкими и разреженными и не распознавались.

## Отправка: как и почему так

Скрипт делает то же, что человек: поиск → номер (лучше) или имя → первый результат → проверка чата (номер или имя
из меню заголовка) → вставка текста → Enter, с паузами как у человека и по одной отправке за раз. Если открылся
чужой чат, ничего не набирается (код 3) и остаётся снимок `…-mismatch.png`. Номер — с кодом страны или без него;
имя — как в Viber (не короче двух букв);
`VIBER_SEND_DRY=1` открывает и проверяет чат, ничего не набирая. Проверено 2026-11-20 на «Моих заметках»: отправка
и отказ на чужом чате. Viber не видит, нажимает ли клавиши человек или скрипт; риск
блокировки — от поведения (массовые сообщения, много новых людей подряд), поэтому только ответы и только по одному.

## Самопроверка и состояние канала

`viber-selftest` на «Моих заметках» (ничего не отправляет): поиск и открытие → меню заголовка даёт имя → поле ввода
принимает текст (вставка, распознавание, стирание); с `SELFTEST_PHONE` в `/home/agent/selftest.env` (вне git) ещё
поиск известного контакта по номеру. Итог привязан к версии Viber. `viber-health` раз в 5 минут: процесс, окно,
экран (вход по QR, «Произошла ошибка», нет связи, окно синхронизации) и самопроверка — после перезапуска или новой
версии запускает её сама, не прошедшую повторяет раз в 30 минут; пока не пройдена — `unverified`, канал недоступен.

## Мост в Stream

`viber-bridge` ходит в Stream по сети `stream_default` (`http://stream:3790`) с `STREAM_VIBER_TOKEN` — токен
создаёт `install.sh` в `/srv/stream/.env` и передаёт столу только его. `install.sh` же обновляет стол вместе с кодом
(если контейнер уже есть). Мост:

- **входящие:** новые строки `notifications.jsonl` (сообщения Viber — заголовок в ограничителях U+2068…U+2069) →
  `POST /api/viber/messages`; номер — `viber-whois` по имени, один раз (без номера — повтор через сутки). С номером
  сообщение попадает в беседу этого номера в Stream, без номера — в беседу `viber:<имя>`;
- **фото, файлы, голосовые:** Viber сохраняет их на столе в `~/Documents/ViberDownloads` (голосовые — `PTT/`) в ту
  же секунду, что приходит уведомление; мост ждёт 15 с, берёт файлы, сохранённые от −5 до +30 с от уведомления,
  загружает (`PUT /api/viber/media/<sha256>`) и прикладывает; заглушка «Фотосообщение» убирается, реакции не
  пересылаются. ❓ Видео и документы — проверить на настоящих;
- **состояние:** раз в минуту итог `viber-health` → `POST /api/viber/pulse` (`ok`; QR — «нужен вход»; прочее —
  «ошибка»); смена состояния — событие «Viber: …» в ленте;
- **ответы:** пока канал `ok`, берёт по одному (`/api/viber/actions/next`), шлёт `viber-send <номер> <текст>`,
  сообщает итог; при перезапуске моста взятая, но не подтверждённая отправка помечается «проверьте в Viber», не
  повторяется. После каждого сценария открыт чат «Мои заметки» (`viber_park`): Viber может молчать об открытом чате.
