# Registry — данные вместо кода

| Файл | Что |
|---|---|
| `fields.yaml` | словарь полей; цели используют только их |
| `intents/*.yaml` | цели по контракту `contracts/intent.schema.json` |
| `connectors.yaml` | коннекторы и их статус: mvp, reserve, candidate, later |

Правила:
- Новая цель, поле, порог или шаблон — правка здесь, не `if` в коде конвейера.
- Меняется смысл цели — `version` +1; старые интерпретации хранят версию, по которой разобраны.
- После правки инструкции или примеров — прогон по `golden/`.
- `$ref: "fields#<name>"` в схеме цели ссылается на поле из `fields.yaml`; загрузчик реестра подставляет его.
