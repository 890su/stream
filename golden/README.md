# Golden set — эталонный набор

50–100 реальных сообщений владельца с правильным разбором. Любая смена модели, инструкции или цели
в `registry/` прогоняется по этому набору; цель шага 3 — ≥80% без правок.

## Как собрать (шаг 0, делает владелец)

1. Неделю всё, что приходит в голову по работе, наговаривай или пиши как обычно — в заметки, себе в
   мессенджер, куда удобно.
2. В конце недели перенеси 50 сообщений в `cases.jsonl` — по одному в строку.
3. Для каждого укажи, что ты на самом деле имел в виду: цель, поля, теги. Сомневаешься — `unknown`.
4. Голосовые — расшифровкой, как текст. Фото чеков — текстом с чека.

Не включай пароли, номера карт и чужие персональные данные сверх нужного (имя и район — можно).

## Формат строки

```json
{"id": "g001", "ts": "2026-11-12T09:15:00+01:00", "input": "заплатил 120 злотых за кабель для Анны", "expected": {"intent": "expense", "fields": {"amount": 120, "currency": "PLN", "category": "materials", "client": "Анна"}, "tags": ["#расход"]}, "note": ""}
```

- `id` — уникальный, `g001`…
- `ts` — когда сказано (нужно для «завтра», «в пятницу»).
- `expected.intent` — имя из `registry/intents/`.
- `expected.fields` — только поля из схемы цели.
- `note` — пояснение, если разбор неочевиден.

## Как считается результат

- Цель совпала, и все обязательные поля совпали → «без правок».
- Цель совпала, но поле отличается → «правка поля».
- Цель не совпала → «ошибка цели».
- Модель ответила `unknown`, а ожидалась другая цель → считается отдельно (лучше честный `unknown`, чем
  уверенная ошибка).

## Реальные сообщения — только локально

Репозиторий публичный, поэтому настоящие сообщения владельца (с клиентами, телефонами, семьёй) лежат в
`golden/cases.local.jsonl` — файл в `.gitignore`. В git остаётся `cases.jsonl` с обезличенными примерами.
Строка локального файла дополнительно содержит `"reviewed": false` — владелец ставит `true`, когда проверил
разметку. Прогон берёт оба файла.

В разметке уже используются цели, которых ещё нет в `registry/intents/`: `work_session` (удалённая работа),
`visit` (выезд), `plan`, `diary`, `feedback`. Это то, что владелец имел в виду; цели заводятся на шаге 3.
